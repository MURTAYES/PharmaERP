# Plan 01-02: Pharmacy Settings, User Management & Append-Only Audit Log Engine

## Goal
Implement the Pharmacy Settings model and CRUD endpoints (profile, receipt width presets, configurable charges, 3-tier expiry windows, category management), the User Management endpoints (create, update role, toggle active status, password reset), and an append-only Audit Logging engine that logs critical security, settings, and auth events.

## User Story
As a Pharmacy Owner, I want to manage staff accounts, customize my pharmacy profile, set receipt printing preferences, and view an immutable audit log of sensitive system events so that our pharmacy operations remain compliant, traceable, and secure.

## Tasks

### Task 1: Pharmacy Settings & Category Management API
- Create `Settings` Mongoose model in `server/src/models/Settings.ts` containing:
  - `pharmacyName`, `address`, `phone`, `email`, `currency` (default "BDT"), `currencySymbol` (default "৳"), `receiptHeader`, `receiptFooter`.
  - `receiptWidth`: `"80mm"` | `"58mm"` (default "80mm").
  - `charges`: Array of `{ id, name, type: 'percentage' | 'fixed', rate, isActive }` (empty array by default).
  - `expiryAlertWindows`: `{ greenDays: 90, yellowDays: 60, redDays: 30 }`.
  - `categories`: Array of strings (e.g. `['Tablet', 'Capsule', 'Syrup', 'Injection', 'Ointment', 'Eye Drops']`).
- Create `SettingsController` and routes `/api/settings` (GET public/authenticated, PUT restricted to `owner`).
- Add default settings initialization in database seed script.

**Files Created/Modified:**
- `server/src/models/Settings.ts`
- `server/src/controllers/settingsController.ts`
- `server/src/routes/settingsRoutes.ts`
- `server/src/scripts/seed.ts`

**Automated Verification:**
```bash

```

### Task 2: User Management CRUD Endpoints (Owner-Only)
- Implement `UserController` in `server/src/controllers/userController.ts`:
  - `GET /api/users`: List all users (excluding password hashes).
  - `POST /api/users`: Create a new user (username, password, fullName, role).
  - `PUT /api/users/:id`: Update user profile, role, or toggle `isActive`.
  - `POST /api/users/:id/reset-password`: Reset a staff member's password.
- Apply `roleGuard(['owner'])` to all user management routes in `server/src/routes/userRoutes.ts`.
- Validate all payloads with Zod schemas.

**Files Created/Modified:**
- `server/src/controllers/userController.ts`
- `server/src/routes/userRoutes.ts`
- `server/src/middleware/validate.ts`

**Automated Verification:**
```bash
npm --prefix server test src/tests/userAudit.test.ts
```

### Task 3: Append-Only Audit Log Engine & Service
- Create `AuditLog` Mongoose model in `server/src/models/AuditLog.ts`:
  - `timestamp`: Date (default Date.now, indexed)
  - `userId`: ObjectId ref User (optional for failed logins)
  - `username`: String
  - `action`: String (e.g. `AUTH_LOGIN`, `AUTH_LOGOUT`, `USER_CREATE`, `USER_UPDATE`, `PASSWORD_RESET`, `SETTINGS_UPDATE`, `STOCK_ADJUSTMENT`, `PRICE_OVERRIDE`)
  - `details`: Object / Record
  - `ipAddress`: String
- Create `AuditService` in `server/src/services/auditService.ts` to log events asynchronously without blocking request handling.
- Hook `AuditService` into `authController`, `userController`, and `settingsController`.
- Create `GET /api/audit` endpoint (Owner only) with pagination and filtering by date range / action.
