# Plan 02-04: End-to-End Inventory Management UI & Real-Time Alert Panels

**Phase:** Phase 2: Inventory & Stock Management (End-to-End)
**Type:** Frontend UI/UX & End-to-End Integration
**Requirements Covered:** INVT-01, INVT-02, INVT-03, INVT-04, INVT-05, INVT-06, INVT-07, INVT-08, INVT-09, INVT-10, INVT-11, INVT-12

## Goal
Build a responsive, high-density Inventory Management UI with real-time type-ahead search (<300ms), 1-click top alert KPI filter chips (Expired, <30d, <60d, <90d, Low Stock), Add/Edit Item modal with live unit conversion hierarchy and derived packaging prices display, Batch Stock Receiving modal with unit selector and MM/YYYY date auto-resolution, Stock Bucket Transfer modal, and Stock Movement History drawer.

## User Stories
- As a Pharmacist or Owner, I can view all medicines in a fast table with stock indicators, unit prices, and batch counts, and filter instantly by clicking top KPI chips.
- As an Owner, I can create or edit medicines with unit conversions (`piecesPerStrip`, `stripsPerBox`) and immediately see the live calculated Strip Price and Box Price formatted as: `Unit Price: ৳ 2.50 (11 x 12: ৳ 330.00) | Strip Price: ৳ 30.00`.
- As a Pharmacist, I can click "Receive Stock", quickly search an item, type batch number and `11/2027` (which auto-completes to end-of-month), choose "Boxes" or "Strips", and submit receiving in seconds without entering cost.
- As an Owner, I can transfer stock between sellable, damaged, and expired buckets with a reason dropdown and note, or write off spoiled items.

## Implementation Details

### 1. API Client Services
- `client/src/services/itemApi.ts`:
  - `getItems(params)`, `searchItems(query)`, `getItemById(id)`, `createItem(data)`, `updateItem(id, data)`, `toggleItemActive(id)`.
- `client/src/services/batchApi.ts`:
  - `receiveStock(data)`, `getBatchesByItem(itemId)`, `updateBatchCost(id, data)`.
- `client/src/services/stockAdjustmentApi.ts`:
  - `transferStock(data)`, `writeOffStock(data)`, `getStockMovements(params)`.
- `client/src/services/alertApi.ts`:
  - `getAlertSummary()`, `getExpiringBatches(tier)`, `getLowStockItems()`.

### 2. Frontend Components & Pages
- `client/src/pages/Inventory.tsx`:
  - Top Alert KPI Bar with 1-click filter buttons:
    - `All Items`
    - `Expired` (Red pill badge with live count)
    - `<30d Critical` (Orange pill badge with count)
    - `<60d Warning` (Yellow pill badge with count)
    - `<90d Notice` (Teal pill badge with count)
    - `Low Stock` (Rose pill badge with count)
  - Search Header:
    - High-speed search bar with debounce (200ms) triggering type-ahead query.
    - Category filter dropdown.
    - "Add Medicine" button (Owner/Pharmacist).
    - "Receive Stock" button (Highlighted primary action).
  - Medicine Table:
    - Columns: Item Code, Trade Name & Generic Name, Category, Shelf Location, Unit Pricing hierarchy breakdown, Sellable Stock (pieces/strips/boxes badge), Earliest Expiry badge, Status, Actions.
    - Expandable Batch Drawer / Row: Shows individual batch numbers, expiry dates, sellable/damaged/expired pieces, cost status (`Cost Missing` tag for Owner to click and resolve), and "Adjust" button (Owner).
- Modals:
  - `ItemModal.tsx`: Medicine form with live reactive unit math and price preview banner.
  - `StockReceivingModal.tsx`: Quick receiving dialog with item search autocomplete, unit converter radio (Box/Strip/Piece), and MM/YYYY date parsing.
  - `StockAdjustmentModal.tsx`: Bucket transfer & write-off dialog with curated reason dropdown and mandatory detail note.
  - `BatchCostModal.tsx`: Owner dialog to resolve uncosted batches.
- Navigation & App Wiring:
  - Add `/inventory` route in `App.tsx`.
  - Add active Inventory tab in `TopNav.tsx`.
  - Update Dashboard KPI tiles to link to active Inventory filter views.
