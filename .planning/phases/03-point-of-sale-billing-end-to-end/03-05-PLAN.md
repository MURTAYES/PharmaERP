# Plan 03-05: Payment Processing Modal, Thermal Receipt Print Engine, and Invoice History

## Goal
Implement the payment processing modal with Cash (tender & change math), Card, MFS (bKash/Nagad/Rocket), and Split payments; a hardware-agnostic thermal receipt print template (58mm/80mm); and an Invoice History lookup page with reprint capabilities.

## Proposed Changes

### 1. Payment Modal Component (`client/src/components/pos/POSPaymentModal.tsx`)
- Multi-tender tabs:
  - **Cash**: Enter received cash, quick preset tender buttons (Exact, ৳ 50, ৳ 100, ৳ 500, ৳ 1000), real-time change due calculation.
  - **Card**: Last 4 digits, card brand.
  - **MFS (Mobile Financial Services)**: Provider dropdown (bKash, Nagad, Rocket, Upay), transaction reference ID.
  - **Split**: Enter cash amount + card/MFS amount with remaining balance validator.
- Customer name and phone number capture for counter receipt.
- "Complete Sale & Print" and "Complete Sale" action buttons.

### 2. Thermal Receipt Print Engine (`client/src/components/pos/ThermalReceiptModal.tsx`)
- Pure CSS print stylesheet with `@media print` rules:
  - Supports 58mm and 80mm receipt widths (configurable via Pharmacy Settings or on-screen toggle).
  - Clean monospace layout with pharmacy header (name, address, phone), invoice number, date/time in Asia/Dhaka timezone, billed by username, customer details.
  - Itemized table: Item name, batch number, expiry date, unit, quantity, unit price, and line total.
  - Financial breakdown: Subtotal, Discount, Taxes/Charges, Grand Total (BDT `৳`), Payment Method, Tendered Cash, and Change Due.
  - Pharmacy footer notice and receipt barcode/QR indicator.
  - Automatic `window.print()` trigger on confirmation.

### 3. Invoices History Page (`client/src/pages/Invoices.tsx`)
- Lists past invoices with search by invoice number, customer phone, or date range.
- Shows key details: Invoice #, Date, Customer, Billed By, Grand Total, Payment Method, Non-FEFO flag, Price Override flag.
- "View & Reprint" action opens thermal receipt modal for fast reprinting.

### 4. Navigation & Routing
- Add routes in `client/src/App.tsx`:
  - `/pos`: Point of Sale billing counter (accessible to Owner & Pharmacist).
  - `/invoices`: Invoices and receipt reprint center.
- Add top navigation bar buttons with active state and keyboard shortcut badges.

## Verification
- Run `npm --prefix client run build` and `npm --prefix server test` to verify full compilation.
- Test complete billing flow: add medicines -> select batch/unit -> override price -> hold & resume -> checkout with cash -> change calculated -> thermal receipt preview & print.
