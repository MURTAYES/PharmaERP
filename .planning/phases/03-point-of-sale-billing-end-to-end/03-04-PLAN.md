# Plan 03-04: High-Speed Counter POS Billing UI with Cart Management, FEFO Selector, Price Overrides & Keyboard Controls

## Goal
Build the high-speed counter POS billing interface optimized for retail pharmacies with instant item search (<300ms), automatic FEFO batch selection, non-FEFO warnings, piece/strip/box unit switching, price override support with visual variance tags, keyboard shortcuts (`F2`, `F4`, `F8`, `F9`), and server-side held bills drawer.

## Proposed Changes

### 1. POS State & Cart Store (`client/src/context/POSContext.tsx` or `client/src/store/posCart.ts`)
- Manage active cart state: line items, quantities, selected unit, active batch, price overrides, discount percentage, customer details, and live total calculations using `decimal.js`.

### 2. POS Billing Components (`client/src/components/pos/`)
- `POSItemSearch.tsx`:
  - Instant type-ahead medicine search (<300ms) by trade name, generic name, or item code.
  - Dropdown displays available sellable stock, unit conversions, and earliest expiry badge.
  - Keyboard navigation: Arrow Up/Down to traverse, Enter to select and add to cart.
- `POSCartTable.tsx` & `POSCartRow.tsx`:
  - Dense, clinical UI optimized for rapid counter scanning.
  - Columns: `#`, `Medicine Name`, `Batch / Expiry (FEFO status)`, `Unit (Pcs / Strip / Box)`, `Quantity`, `Unit Price (with override)`, `Line Total`, `Actions`.
  - Batch Selector dropdown/modal: highlights FEFO batch, shows expiry status badge, displays non-FEFO warning tag when another batch is selected.
  - Unit Switcher: Toggles between Piece, Strip, Box, dynamically adjusting unit price and converting total pieces without fractions.
  - Price Override popover/inline input: allows editing the selling price with instant variance tag (e.g., `-৳ 2.00`).
- `POSHeldBillsDrawer.tsx`:
  - Slide-out drawer or modal showing held bills.
  - Allows quick hold (`F8`) with optional note, and one-click resume (`F9`) which loads items directly into active cart.
- `POSSummaryFooter.tsx`:
  - Displays Subtotal, Discount percentage input, active Settings Charges (VAT / Tax / Fees), and Grand Total in big bold font.

### 3. POS Page (`client/src/pages/POS.tsx`)
- Integrates all components into a full-screen layout.
- Global keyboard event listeners:
  - `F2` or `/`: Focus item search bar.
  - `F4` or `Ctrl+Enter`: Open checkout / payment modal.
  - `F8`: Hold active bill.
  - `F9`: Open held bills list.
  - `Escape`: Cancel modal or clear input.
- Offline/Network status banner: prevents submission if network disconnects.

## Verification
- Run `npm --prefix client run build` to verify clean compilation.
- Verify sub-300ms item search and smooth keyboard navigation in browser.
