## 1. Objectives & Success Criteria
- [ ] Connect `useBarcodeScanner` into `POS.tsx` so physical scans instantly resolve medicines.
- [ ] Implement duplicate scan handling: if medicine is already in cart, automatically increment quantity by `+1` piece and flash row.
- [ ] Implement multi-batch resolution (`POSScannerBatchModal.tsx`): if more than 1 active batch exists in stock, present quick confirmation popover to let cashier pick the batch in their hand.
- [ ] Connect `useBarcodeScanner` into `StockReceivingModal.tsx`: scanning an incoming product auto-selects it from catalog, populates brand/packaging details, and focuses the Batch Number & Expiry Date inputs.
- [ ] Implement `UnknownBarcodeModal.tsx`: if an unknown barcode is scanned, prompt cashier/owner to either link it to an existing item or create a new master product.

## 2. Tasks

### Task 1: Multi-Batch Quick Selection Popover (`POSScannerBatchModal.tsx`)
- Create compact modal/popover that opens when a scanned item has >1 active batches:
  - Displays Medicine Trade Name and Generic Name.
  - Lists batches with: Batch Number, Expiry Date (MM/yy with FEFO badge), Available Pcs, and MRP.
  - Keyboard-navigable (Arrow keys + Enter, or clicking).
  - Selecting adds that chosen batch to cart and closes popover.

### Task 2: POS Terminal Zero-Click Auto-Add (`POS.tsx`)
- Mount `useBarcodeScanner` in `POS.tsx`:
  - When barcode is scanned:
    - Look up barcode via `inventoryApi.lookupBarcode(code)`.
    - If found:
      - Check if already in `lines`:
        - Yes: update line quantity (`quantity + 1`), recalculate line total, highlight line with emerald pulse animation.
        - No:
          - If 0 active batches: display warning toast "Medicine is out of stock in all batches".
          - If 1 active batch: immediately append new line to cart with that batch.
          - If >1 active batches: open `POSScannerBatchModal` for cashier selection.
    - If not found:
      - Open `UnknownBarcodeModal` passing scanned code.

### Task 3: Inventory Receive Batch Auto-Ingestion (`StockReceivingModal.tsx`)
- Mount scanner listener inside `StockReceivingModal`:
  - When scanner fires inside receiving modal:
    - Calls `inventoryApi.lookupBarcode(code)`.
    - If found:
      - Sets `selectedItemId` to matched item.
      - Auto-fills trade name, brand name, category, and pieces-per-box.
      - Programmatically shifts input focus to `batchNumber` input field.
      - Displays green pill "Product Auto-Detected via Barcode".

### Task 4: Unknown Barcode Link & Register Workflow (`UnknownBarcodeModal.tsx`)
- Build modal that displays when an unrecognized code is scanned:
  - Header: "Unknown Barcode: [code]"
  - Action 1: "Link to Existing Product" -> searchable dropdown of master catalog. Selecting an item calls `updateItem` appending barcode to `item.barcodes`.
  - Action 2: "Add New Master Product" -> opens `ItemModal` pre-populated with `barcodes: [code]`.
  - Action 3: Cancel.

### Task 5: Inventory Main Screen Scanner Search Integration (`Inventory.tsx`)
- When on the main Inventory page (with no modal open), scanning a barcode filters the inventory table directly to that product.
