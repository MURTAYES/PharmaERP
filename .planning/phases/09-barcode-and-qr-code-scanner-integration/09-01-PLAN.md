## 1. Objectives & Success Criteria
- [ ] Create `GET /api/inventory/items/lookup-barcode?code=:code` endpoint that resolves an item by `barcodes`, `qrCode`, or `itemCode`, as well as batch-specific barcodes, returning item details and active sellable batches with FEFO sorting.
- [ ] Implement unit tests verifying sub-50ms lookup performance, active batch extraction, and not-found responses.

- [ ] Implement `useBarcodeScanner.ts` custom React hook that captures high-speed keyboard-wedge bursts (<35ms ICI ending in Enter/Tab), isolates physical scans from human typing, and fires an `onScan(code)` callback.

## 2. Tasks

### Task 1: Backend Lookup Endpoint & Controller (`itemController.ts` & `itemRoutes.ts`)
- Implement `lookupBarcode(req: Request, res: Response)`:
  - Sanitizes and trims input code.
  - Queries `Item` where `barcodes: code`, `qrCode: code`, or `itemCode: code.toUpperCase()`.
  - Also queries `Batch` where `barcode: code` or `qrCode: code` to identify specific batch links if item wasn't directly matched.
  - If item found:
    - Queries active batches (`itemId: item._id, qtySellable: { $gt: 0 }, expiryDate: { $gt: new Date() }`), sorted by `expiryDate: 1` (FEFO).
    - Returns `{ found: true, item, activeBatches, matchingBatchId }`.
  - If not found:
    - Returns `{ found: false, code }`.
- Route: Mount `GET /lookup-barcode` on `itemRouter`.

### Task 2: Automated Tests (`barcodeLookup.test.ts`)
- Add tests in `server/src/tests/barcodeLookup.test.ts` verifying:
  - Lookup by exact barcode in `item.barcodes`.
  - Lookup by batch barcode.
  - FEFO sorting on returned active batches.
  - Return of `{ found: false }` for unrecognized codes.

### Task 3: Client Inventory API Service (`inventoryApi.ts`)
- Add `lookupBarcode(code: string): Promise<BarcodeLookupResponse>` to `inventoryApi.ts`.

### Task 4: Audio Confirmation Synthesizer (`audioChime.ts`)
- Build zero-dependency sound helper using `window.AudioContext`:
  - `playScannerBeep(type?: 'success' | 'warning' | 'error')`:
    - `success`: 1950Hz crisp tone (60ms).
    - `warning`: 800Hz / 400Hz double tone.
    - `error`: 300Hz low buzz.

### Task 5: Hardware Scanner Hook (`useBarcodeScanner.ts`)
- Create React hook `useBarcodeScanner({ onScan, enabled = true, minLength = 3, maxIntervalMs = 35 })`:
  - Global `window.addEventListener('keydown')`.
  - Buffer characters with high-resolution timestamps (`performance.now()`).
  - If time between keystrokes exceeds `maxIntervalMs`, reset buffer (human typing detected).
  - If terminating key (`Enter` or `Tab`) is hit and buffer length >= `minLength`, trigger `e.preventDefault()`, fire `onScan(buffer)`, play `playScannerBeep('success')`, and clear buffer.
  - Clean up event listener on unmount.
