# Plan 04-02: Supplier Return Models, Owner Bucket Deductions & Return API Endpoints

**Phase:** 04 — Returns & Credit Notes (End-to-End)  
**Plan:** 02 of 03  
**Type:** Backend Supplier Returns & Full API Surface  

---

## 1. Objectives & Deliverables
1. Create `server/src/models/SupplierReturn.ts` schema with batch snapshots, supplier details, and owner cost valuation.
2. Extend `server/src/models/StockMovement.ts` with movement type `'SUPPLIER_RETURN'` if needed.
3. Implement `supplierReturnService.ts` with atomic transaction & `$gte` concurrency guards to deduct stock from `damaged` or `expired` buckets.
4. Build REST API routes in `server/src/controllers/returnController.ts` and `server/src/routes/returnRoutes.ts`:
   - `GET /api/returns/invoices/search`: Search past invoices for returns.
   - `GET /api/returns/invoices/:id/return-summary`: Fetch invoice return history, returnable quantities, and past credit notes.
   - `POST /api/returns/sales`: Process a customer sales return and issue a Credit Note.
   - `GET /api/returns/credit-notes`: List credit notes with pagination and search.
   - `GET /api/returns/credit-notes/:id`: Get single credit note detail for receipt printing.
   - `POST /api/returns/supplier`: Process a supplier return (Owner only).
   - `GET /api/returns/supplier`: List supplier return invoices (Owner only).
5. Add unit and integration tests in `server/src/tests/supplierReturn.test.ts`.

## 2. Step-by-Step Implementation

### Step 1: Create `SupplierReturn.ts` Model
- Path: `server/src/models/SupplierReturn.ts`
- Track lines, batchId, fromBucket (`damaged` | `expired`), quantities, and estimated credit memo value.

### Step 2: Implement `supplierReturnService.ts`
- Path: `server/src/services/supplierReturnService.ts`
- Ensure `$gte` guard on `qtyDamaged` or `qtyExpired`.
- Generate `SRT-000001` sequential numbering.

### Step 3: Create Controller & Routes
- Path: `server/src/controllers/returnController.ts` & `server/src/routes/returnRoutes.ts`
- Protect supplier endpoints with `requireRole('owner')`.
- Hook up routes in `server/src/app.ts`.

### Step 4: Add Automated Tests
- Test supplier return deduction, insufficient damaged stock rejection, and role-based access.
