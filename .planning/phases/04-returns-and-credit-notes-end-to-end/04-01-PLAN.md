# Plan 04-01: Sales Return Data Models, Pricing Engine Refund Math & Atomic Return Service

**Phase:** 04 — Returns & Credit Notes (End-to-End)  
**Plan:** 01 of 03  
**Type:** Backend Data Model, Pricing Math & Transaction Engine  

---

## 1. Objectives & Deliverables
1. Create `server/src/models/CreditNote.ts` Mongoose schema with `Decimal128` fields, line snapshots, refund payment modes, and audit details.
2. Extend `server/src/utils/pricingEngine.ts` with `calculateRefundPricing()` to calculate proportional discount deductions and tax adjustments with `Decimal.js`.
3. Create `server/src/services/returnService.ts` executing atomic multi-document sales return transactions:
   - Validates previous return quantities against invoice lines to prevent over-returns.
   - Atomically increments appropriate batch stock bucket (`qtySellable`, `qtyDamaged`, or `qtyExpired`).
   - Creates immutable `StockMovement` ledger entry (`RETURN_RESTOCK`).
   - Generates gap-free sequential `CN-000001` credit note numbers using `Counter.getNextSequence`.
   - Updates original invoice status (`RETURNED_PARTIAL` or `RETURNED_FULL`).
4. Unit tests covering proportional refund calculations and over-return prevention in `server/src/tests/returns.test.ts`.

---

## 2. Step-by-Step Implementation

### Step 1: Create `CreditNote.ts` Model
- Path: `server/src/models/CreditNote.ts`
- Schema with indexes on `creditNoteNumber`, `invoiceId`, `createdAt`.

### Step 2: Implement Proportional Refund Math in `pricingEngine.ts`
- Calculate returned subtotal using sold unit price per piece.
- Calculate proportional discount = `(returnedSubtotal / invoiceSubtotal) * invoiceDiscountAmount`.
- Recalculate percentage charges proportionally on `(returnedSubtotal - discountRefund)`.
- Keep fixed charges non-refundable.

### Step 3: Implement `returnService.processSalesReturn`
- Path: `server/src/services/returnService.ts`
- Use MongoDB replica set session transactions.
- Atomically restore batch quantities and create `StockMovement` records.

### Step 4: Add Automated Unit Tests
- Path: `server/src/tests/returns.test.ts`
- Test full return, partial return with flat discount, partial return with percentage tax, and over-return boundary errors.
