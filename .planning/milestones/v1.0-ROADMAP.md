## Key Technical Decisions Shipped
1. **Vertical MVP Slices**: Every phase delivered database + backend API + frontend UI + automated tests.
2. **Strict Decimal Precision**: MongoDB `Decimal128` + client `decimal.js` for arbitrary-precision money math.
3. **Multi-Document Concurrency Guard**: Atomic `$gte` conditions inside MongoDB replica set transactions to guarantee non-negative stock.
4. **Field-Stripping RBAC**: Express serializer strips cost, purchase price, profit, and margin fields at the API level for Pharmacists.
5. **FEFO Protocol**: Earliest-expiring batches automatically prioritized with explicit non-FEFO warning tags.
6. **Thermal Printing**: Clean 58mm/80mm browser print formatting using `@page` CSS stylesheets.
