# Plan 02-01: Item Master Data Models, Multi-Unit Conversions & Type-Ahead Search API

**Phase:** Phase 2: Inventory & Stock Management (End-to-End)
**Type:** Backend Data Model & Core Search Service
**Requirements Covered:** INVT-01, INVT-02, INVT-03, INVT-04

## Goal
Implement the core `Item` Mongoose model with Decimal128 `mrpPerPiece`, unit conversion hierarchy (`piecesPerStrip`, `stripsPerBox`), derived packaging prices, category association, and high-performance type-ahead search API (<300ms) with text indexing and auto-generated unique item codes (`MED-000001`).

## User Stories
- As an Owner, I can create and update medicine items with trade names, generic names, categories, shelf locations, low-stock thresholds, and multi-unit conversions.
- As a Pharmacist or Owner, I can search medicines by trade name, generic name, or item code in <300ms with real-time aggregated sellable stock counts.

## Implementation Details

### 1. Item Model (`server/src/models/Item.ts`)
- Fields:
  - `tradeName` (string, required, indexed)
  - `genericName` (string, required, indexed)
  - `itemCode` (string, unique, auto-generated sequence e.g. `MED-000001`)
  - `categoryId` (ObjectId -> Category, required)
  - `manufacturer` (string, required)
  - `shelfLocation` (string, optional)
  - `unitHierarchy`:
    - `baseUnit`: constant `'piece'`
    - `piecesPerStrip`: number (min: 1, default: 1)
    - `stripsPerBox`: number (min: 1, default: 1)
  - `mrpPerPiece`: `Types.Decimal128` (min: 0, required)
  - `lowStockThresholdPieces`: number (min: 0, default: 20)
  - `isActive`: boolean (default: true)
- Virtuals / Methods for Derived Prices:
  - `stripPrice` = `mrpPerPiece * piecesPerStrip`
  - `boxPrice` = `mrpPerPiece * piecesPerStrip * stripsPerBox`
  - `totalPiecesPerBox` = `piecesPerStrip * stripsPerBox`
- Indexes:
  - Compound text index on `{ tradeName: 'text', genericName: 'text', itemCode: 'text' }`
  - B-tree index on `{ tradeName: 1, genericName: 1 }`
  - Unique index on `{ itemCode: 1 }`

### 2. Item Controller & Validation (`server/src/controllers/itemController.ts`)
- Endpoints:
  - `GET /api/items`: List all items with pagination, category filter, and optional search term.
  - `GET /api/items/search?q=...`: High-speed type-ahead autocomplete (<300ms) returning top 15 matches with current total sellable stock across batches.
  - `GET /api/items/:id`: Detailed item view with all active batches and stock breakdown.
  - `POST /api/items`: Create item (Owner & Pharmacist). Auto-increments item code if not provided.
  - `PUT /api/items/:id`: Update item attributes.
  - `PATCH /api/items/:id/toggle-active`: Toggle active status.

### 3. Automated Tests (`server/src/tests/item.test.ts`)
- Validate item creation with sequence numbering (`MED-000001`).
- Validate unit conversion math and derived packaging prices.
- Validate type-ahead search matching across tradeName and genericName with response time < 300ms.
