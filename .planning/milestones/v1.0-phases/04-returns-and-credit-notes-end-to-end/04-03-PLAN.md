# Plan 04-03: Returns Management UI, Refund Modals, Thermal Credit Note Receipts & Supplier Return Creator

**Phase:** 04 — Returns & Credit Notes (End-to-End)  
**Plan:** 03 of 03  
**Type:** Frontend UI, Modals, State Management & Receipt Printing  

---

## 1. Objectives & Deliverables
1. Build `client/src/services/returnApi.ts` client API integration for search, return processing, and credit note retrieval.
2. Build `client/src/components/returns/SalesReturnModal.tsx`:
   - Invoice item selection with remaining returnable quantity indicators.
   - Unit conversion toggles (piece/strip/box) with whole integer validation.
   - Destination bucket selector (`Sellable`, `Damaged`, `Expired`).
   - Live proportional refund summary card.
   - Reason category selection and explanation notes.
3. Build `client/src/components/returns/CreditNoteReceiptModal.tsx`:
   - 80mm & 58mm thermal print template for Credit Notes matching pharmacy branding.
4. Build `client/src/components/returns/SupplierReturnModal.tsx`:
   - Owner-only modal to select damaged/expired batches and generate `SRT-000001` return vouchers.
5. Create `client/src/pages/Returns.tsx` and integrate navigation route in `TopNav.tsx` and `App.tsx`.

---

## 2. Step-by-Step Implementation

### Step 1: Create `returnApi.ts`
- Functions: `searchInvoicesForReturn`, `getInvoiceReturnSummary`, `processSalesReturn`, `getCreditNotes`, `getCreditNoteById`, `createSupplierReturn`, `getSupplierReturns`.

### Step 2: Build `SalesReturnModal.tsx`
- Interactive item list with remaining quantity guards.
- Dynamic refund calculation showing item refund, proportional discount deduction, and net refund.

### Step 3: Build `CreditNoteReceiptModal.tsx`
- Thermal receipt styling with `@media print` rules, pharmacy header, refund summary, and items returned.

### Step 4: Build `SupplierReturnModal.tsx`
- Damaged / expired batch inventory picker with quantity verification and supplier invoice references.

### Step 5: Build `Returns.tsx` Page & TopNav Link
- Main returns hub with two tabs: **Customer Returns (Credit Notes)** and **Supplier Returns (Owner)**.
- Integrated into router and TopNav navigation.

---

## 3. Verification Criteria
- `npm --prefix client run build` compiles with 0 errors.
- End-to-end user return workflow tested from invoice lookup to stock restoration and thermal receipt generation.
