# Plan 03-01: Invoicing Data Models, Pricing Engine with Decimal.js, and Sequential Counter Service

## Goal
Implement the MongoDB schemas for Invoices and Held Bills, an arbitrary-precision pricing calculation engine (`decimal.js`), and upgrade the atomic sequence generator (`Counter.ts`) to support transactional operations.

## Proposed Changes

### 1. Invoicing & Held Bill Data Models
- Create `server/src/models/Invoice.ts`:
  - Fields: `invoiceNumber`, `billedBy`, `billedByName`, `customerName`, `customerPhone`, `lines`, `subtotal`, `discountPercent`, `discountAmount`, `charges`, `totalCharges`, `grandTotal`, `payment`, `status`, `hasPriceOverride`, `hasNonFefoBatch`, timestamps.
  - Subdocuments: `IInvoiceLineItem` with immutable snapshots of item trade/generic name, batch number, expiry date, unit hierarchy, integer pieces, unit prices, cost per piece (Decimal128), price override details, and non-FEFO flag.
  - Indexes: `invoiceNumber` (unique), `createdAt` (desc), `billedBy`, `hasPriceOverride`, `hasNonFefoBatch`.
- Create `server/src/models/HeldBill.ts`:
  - Temporary storage of active carts with user attribution, customer info, item lines, and notes.

### 2. Pricing Engine Utility (`server/src/utils/pricingEngine.ts`)
- Implement pure calculation functions using `decimal.js`:
  - `calculateLineItem(unitPrice, quantity, unit, unitHierarchy)` -> computes `quantityPieces`, `unitPricePerPiece`, `lineTotal`.
  - `calculateInvoiceTotals(lines, discountPercent, activeCharges)`:
    - `subtotal` = sum of line totals
    - `discountAmount` = `subtotal * (discountPercent / 100)`
    - `netAfterDiscount` = `subtotal - discountAmount`
    - `percentageCharges` = applied on `netAfterDiscount`
    - `fixedCharges` = fixed amount per invoice
    - `grandTotal` = `ROUND_HALF_UP(netAfterDiscount + charges, 2)`
  - `calculateChangeDue(grandTotal, tenderedAmount)`.

### 3. Session-Aware Counter Generator (`server/src/models/Counter.ts`)
- Update `getNextSequence(counterId, prefix, padLength, session?: mongoose.ClientSession)` to accept an optional Mongoose session for inclusion in multi-document transactions.

### 4. Serializer Update (`server/src/middleware/serializer.ts`)
- Extend serializer to strip `purchaseCostPerPiece`, `costSnapshot`, and margin fields from `Invoice` line items when the requester role is `pharmacist`.

### 5. Automated Tests
- Create `server/src/tests/pricingEngine.test.ts`:
  - Verify exact decimal calculation results, multi-item subtotals, compound tax/VAT percentages, fixed fees, and rounding behavior.

## Verification
- `npm --prefix server test` passes all tests cleanly.
