# Plan 05-04: Reports Center UI, Tabular Analysis & Client-Side CSV Export

**Phase:** 05 — Analytics & Reporting Suite (End-to-End)  
**Plan:** 04 of 04  
**Type:** Frontend Reports Center, Interactive Tables & CSV Exporter  

---

## 1. Objectives & Deliverables
1. Build `client/src/utils/csvExporter.ts` universal client-side CSV export utility supporting custom column headers and formatted values.
2. Build `client/src/pages/Reports.tsx` containing comprehensive tabbed report views:
   - **Sales Summary Report:** Daily/monthly totals, invoice counts, discounts, and revenue.
   - **Sales by Item Report:** Medicine trade name, pieces sold, revenue, average price.
   - **Profit & Loss Report (Owner Only):** Revenue, cost, gross profit, margin %, uncosted lines.
   - **Price Override Audit:** Overridden sales, original MRP, variance, staff name, and date.
   - **Non-FEFO Audit:** Chosen batch vs suggested earlier expiring batch.
   - **Stock Valuation:** Total items & inventory worth at retail MRP vs purchase cost.
   - **Returns & Credit Notes:** Customer returns & supplier return summary.
   - **Stock Movement Ledger:** Chronological audit trail of all inventory transactions.
3. Add 1-click **Export to CSV** button on all report tabs.
4. Mount `/reports` in `TopNav.tsx` and `App.tsx` (accessible to Owner).

---

## 2. Step-by-Step Implementation

### Step 1: Implement CSV Exporter
- Path: `client/src/utils/csvExporter.ts`
- Format array of objects to CSV string, encode BOM for Excel compatibility, and trigger download.

### Step 2: Implement `Reports.tsx`
- Tab switcher with badge indicators.
- Filter toolbar: date range pickers (`startDate`, `endDate`), category/item filters, search bar.
- High-contrast data tables matching the modern healthcare theme.

### Step 3: Enable Reports Route & TopNav Link
- Register `/reports` route in `App.tsx` (Owner protected).
- Activate Reports link in `TopNav.tsx`.

---

## 3. Verification Criteria
- `npm --prefix client run build` builds with 0 errors.
- Every report tab renders filtered data correctly and downloads verified CSV files.
