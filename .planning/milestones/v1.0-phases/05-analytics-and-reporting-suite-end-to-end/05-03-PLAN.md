**Phase:** 05 — Analytics & Reporting Suite (End-to-End)  
**Plan:** 03 of 04  
**Type:** Frontend Executive Dashboard UI & Data Visualization  

---

## 1. Objectives & Deliverables
1. Build `client/src/services/reportApi.ts` client API service.
2. Upgrade `client/src/pages/Dashboard.tsx` with live analytics for Owner role:
   - Today's Total Sales (৳) with comparison to yesterday.
   - Total Invoices Billed & Average Ticket Size.
   - Payment Method Distribution (Cash vs Card vs MFS breakdown).
   - Real-time Expiry & Low-Stock Alerts summary widget.
   - Top 5 Best-Selling Medicines table.
   - Quick Action Shortcuts (New Sale, Receive Stock, Process Return, View Reports).
3. Ensure clean, elegant view for Pharmacist role (focused on daily counter metrics and active alerts without exposing cost/profit data).

## 2. Step-by-Step Implementation

### Step 2: Implement Redesigned Dashboard Component
- Use React Query (`useQuery`) for auto-refetching and live metric counters.
- Visual status cards matching the mint/teal clinical aesthetic.
