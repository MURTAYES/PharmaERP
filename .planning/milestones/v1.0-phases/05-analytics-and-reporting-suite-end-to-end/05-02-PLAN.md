# Plan 05-02: Specialized Audit Reports & REST API Surface

**Phase:** 05 — Analytics & Reporting Suite (End-to-End)  
**Plan:** 02 of 04  
**Type:** Backend Specialized Reports & API Routes  

---

## 1. Objectives & Deliverables
1. Extend `server/src/services/reportService.ts` with specialized audit and inventory pipelines:
   - `getPriceOverrideReport(query)`: Lines where `isPriceOverridden: true`, showing original price, override price, variance, staff name, and date.
   - `getNonFefoReport(query)`: Lines where `isNonFefo: true`, showing chosen batch vs earlier expiring batch.
   - `getStockValuationReport()`: Inventory valued at Retail Price (MRP) vs Purchase Cost across all batches.
   - `getReturnsReport(query)`: Aggregated customer returns (Credit Notes) and supplier returns (SRT).
   - `getStockMovementLedger(query)`: Paginated chronological ledger of all stock movements.
2. Build `server/src/controllers/reportController.ts` and `server/src/routes/reportRoutes.ts`:
   - All endpoints protected by `requireAuth` and `requireRole(['owner'])`.
3. Register report routes in `server/src/routes/index.ts`.
4. Automated tests in `server/src/tests/specializedReports.test.ts`.

---

## 2. Step-by-Step Implementation

### Step 1: Implement Audit & Inventory Pipelines
- Price override query with variance calculation.
- Non-FEFO query with suggested batch comparison.
- Stock valuation aggregating `qtySellable * mrp` and `qtySellable * purchasePrice`.
- Stock movement ledger with pagination and filters.

### Step 2: Implement Controller & Routes
- Create `reportController.ts` and `reportRoutes.ts`.
- Mount under `/api/reports` in `server/src/routes/index.ts`.

### Step 3: Add Automated Tests
- Test report response formats and role access security.
