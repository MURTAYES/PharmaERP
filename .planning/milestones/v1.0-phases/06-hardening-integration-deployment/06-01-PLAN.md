# Plan 06-01: Role-Leak Security Integration Suite & Concurrency Stress Testing

**Phase:** 06 — Hardening, Integration & Deployment  
**Plan:** 01 of 02  
**Type:** Security Audit & Concurrency Stress Testing  

---

## 1. Objectives & Deliverables
1. Build comprehensive automated security tests in `server/src/tests/securityAudit.test.ts`:
   - Validates that response serializer strips all cost/profit/valuation keys across all nested payloads (batches, items, invoices, movements) for the Pharmacist role.
   - Validates that Owner role receives full financial data.
   - Validates that unauthorized roles are rejected with 403 on `/api/reports/*`, `/api/users/*`, `/api/settings/*`, and `/api/returns/supplier/*`.
2. Build concurrency race condition tests in `server/src/tests/concurrencyGuard.test.ts`:
   - Simulates simultaneous parallel checkouts against a single batch to verify `$gte` guard prevents negative stock.

---

## 2. Step-by-Step Implementation

### Step 1: Create `securityAudit.test.ts`
- Tests response serializer on arrays, objects, and deeply nested structures.
- Tests role protection middleware.

### Step 2: Create `concurrencyGuard.test.ts`
- Tests atomic conditional decrements and verifies that concurrent operations abort on insufficient stock.
